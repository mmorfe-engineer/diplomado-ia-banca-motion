## Arquitectura e inserción quirúrgica

```mermaid
flowchart LR
  V1["V1 approved blocks"] --> P["Original prefix · scenes 01–16 · 13,632 frames"]
  V1 --> S["Original suffix · scenes 17–21 · 2,325 frames"]
  D["V2 data.json + five private WAVs"] --> R["React/SVG · Strategic + Refinements"]
  R --> C["300-frame recoverable chunks · 5,006 frames"]
  P --> A["FFmpeg · video stream copy + PCM audio assembly"]
  C --> A
  S --> A
  A --> Q["QA · pixel hashes, subtitles, decode and approval"]
  Q --> M["V2 · 20,963 frames · 26 scenes"]
```

Los componentes globales y las escenas V1 permanecen intactos. V2 inserta **16A–16E después de Isabel y antes del antecedente bancario**. Las escenas 17/18 conservan su locución original continua. Véanse [arquitectura](docs/ARCHITECTURE.md), [secuencia narrativa](docs/SCENE-BY-SCENE.md) y [sincronización por palabras](docs/AUDIO-SYNCHRONIZATION.md).

## Reproducir y modificar

```bash
git clone https://github.com/mmorfe-engineer/diplomado-ia-banca-motion.git
cd diplomado-ia-banca-motion
npm ci
npm run typecheck
npm run docs:check
npm run studio
```

Studio registra `V2-negocios`, `V2-credito`, `V2-operaciones`, `V2-planificacion`, `V2-finanzas` y `DiplomadoIA-V2-Estrategico`, además del bloque original de revisión V1.

```bash
# V1: select the original block (other choices: 03-06, 07-10, 11-16)
npm run studio -- --props='{"block":"17-21"}'

# Authorized private media required for full audiovisual output
npm run v2:render
npm run v2:assemble
npm run v2:qa
```

**Reproducible desde el repositorio público:** instalación, typecheck, validación documental e inspección del código. La producción requiere voces y SFX privados, pistas V1 aprobadas, PCM, acceso a fuentes tipográficas y configuración local de navegador/FFmpeg. Disponer del código no garantiza un re-render idéntico bit a bit. [Comandos y límites](docs/REPRODUCIBILITY.md) · [Build/render](docs/BUILD-AND-RENDER.md) · [Guía de modificación](docs/MODIFICATION-GUIDE.md).
